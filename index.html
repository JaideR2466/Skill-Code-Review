¿Qué hace la skill?

Actúa como un Software Engineer Senior revisando tu código en segundos.

La skill examina profundamente cualquier fragmento de código o archivo para identificar fallos de arquitectura, duplicidades, vulnerabilidades de seguridad y oportunidades de mejora antes de llegar a producción.

Detección de Code Smells & Seguridad

Identifica inyecciones, fugas de memoria, variables globales, antipatrones y falta de validación.

Eficiencia y Rendimiento Algorítmico

Detecta bucles redundantes $O(n^2)$, consultas pesadas desoptimizadas y uso ineficiente de memoria.

Propuesta de Refactorización Directa

No solo critica: entrega la versión optimizada en código limpio, mantenible y listo para usar.

6 Pilares de Análisis Profundo

La skill evalúa tu código exhaustivamente combinando teoría de la computación y estándares de la industria.

Legibilidad & Estilo

Evaluación de nombres de variables explícitos, convenciones del lenguaje (PEP8, TypeScript guidelines) y eliminación de complejidad innecesaria.

Principios SOLID

Verificación estricta de Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation y Dependency Inversion.

Patrones de Diseño

Recomendación de patrones oportunos (Factory, Strategy, Observer, Adapter) para simplificar la extensibilidad y desacoplar componentes.

Seguridad OWASP

Detección preventiva de inyecciones SQL/Command, exposición de secretos/API Keys, manipulación insegura de inputs y saneamiento.

Rendimiento & Memoria

Optimización algorítmica, reducción de accesos a BD/E-S, prevención de memory leaks y uso eficiente de estructuras de datos.

Refactorización Inteligente

Entrega de código refactorizado listo para copiar y pegar, manteniendo el comportamiento funcional exacto pero con mayor calidad.

Demostración Visual: Antes vs Después

Mira cómo la skill transforma código desordenado e ineficiente en código conciso, tipado y legible.

usuario.py (Antes - Problemático)
Code Smells: 4 
# Malas prácticas: Nombres difusos, falta de tipos y bucle ineficiente
def obtener_datos(usuario):
    datos = []
    for u in usuario:
        datos.append({"id": u["id"], "nombre": u["nombre"]})
    return datos

✖ Variable `usuario` en singular cuando es una lista.

✖ Sin Type Hints para estricta verificación.

✖ Bucle `for` imperativo innecesario en lugar de List Comprehension.

usuario.py (Después - Refactorizado)
Clean Code 100% 
# Buenas prácticas: Tipado estricto, nombres claros y List Comprehension
def obtener_datos(usuarios: list[dict]) -> list[dict]:
    return [
        {"id": u["id"], "nombre": u["nombre"]} 
        for u in usuarios
    ]

✔ Nombre plural `usuarios` que representa la colección real.

✔ Anotaciones de tipos Python 3.9+ (`list[dict]`).

✔ Código idiomático, limpio, legible y optimizado.

# Code Review & Clean Code AI Skill

Skill avanzada de inteligencia artificial diseñada para actuar como un Senior Software Engineer & Code Auditor especializado en Clean Code, Principios SOLID y Seguridad.

🎯 Objetivo

Transformar fragmentos de código crudo en soluciones listas para producción con alta legibilidad, cero vulnerabilidades y óptima eficiencia.

⚡ Cuándo Utilizarla

  • Antes de abrir un Pull Request / Code Review.
  • Al detectar cuellos de botella de rendimiento.
  • Para refactorizar código legacy.

📐 Principios SOLID Analizados:

SRP (Single Resp)
OCP (Open/Closed)
LSP (Liskov Subst)
ISP (Interface Seg)
DIP (Dependency Inv)

📋 Estructura de Respuesta de la Skill:

  1. Resumen General: Diagnóstico y puntuación global de calidad.
  2. Puntos Críticos o Code Smells: Explicación de errores y vulnerabilidades.
  3. Propuesta de Mejora / Refactorización: Snippet de código optimizado con comentarios explicativos.
  4. Buenas Prácticas Adicionales: Consejos de arquitectura para escalar el proyecto.
